# Xmusic for Windows

Windows 桌面播放器，使用 Electron、React 和 TypeScript。当前版本 0.3.0，提供本地音乐库、在线歌曲搜索与播放、下载管理、收藏、最近播放、播放队列、完整歌词页和桌面悬浮歌词。

## 开发与运行

需要 Windows 10/11 x64、Node.js **22.12.0 或更高版本**以及 npm。CI 使用 Node.js 24。首次运行和打包需要联网下载依赖、Electron 运行时及打包工具。Electron 44 会在首次调用时按需下载运行时；`npm ci` 成功不代表已下载 Windows 二进制。

在仓库根目录执行：

```powershell
cd desktop
npm ci
npm run dev
```

`npm run dev` 同时启动 Vite 和 Electron，开发服务使用 `http://127.0.0.1:5173`；该端口需空闲。关闭客户端或按 `Ctrl+C` 会停止开发服务。

运行生产构建：

```powershell
npm run build
npm start
```

`npm start` 直接加载已有的 `dist`，不会自动构建。`npm run dev:web` 只启动浏览器界面预览，浏览器内没有桌面桥接，无法导入本地文件或调用在线音乐服务。

## 已实现的功能

- 多选导入本地音频或递归导入文件夹，读取歌曲名、歌手、专辑、时长、同名图片和内嵌封面；支持筛选音乐库与移除记录。
- 在线搜索支持歌曲与歌单切换，歌曲每页 30 首、歌单每页 20 张，分别保留结果并支持继续加载；歌单可打开详情、收藏及播放，返回保留搜索结果。搜索、本地音乐、我喜欢、榜单和歌单共用批量操作与歌曲菜单。
- 播放、暂停、上一首、下一首、进度拖动、音量与静音；支持列表循环、单曲循环和随机播放。
- 播放队列去重、加入、移除与清空；收藏和最近播放列表，最近播放可单独清空。
- 在线歌词优先使用 QRC 逐字时间轴，按实际播放进度渐进染色；支持本地同名 LRC、点击歌词跳转、一行多个时间标签及 LRC 时间偏移。
- 探索音乐展示与移动端一致的榜单和歌单，支持胶囊分类、详情浏览、分类分页和关键词搜索。
- 我的歌单支持新建、重命名、删除、收藏在线歌单，以及通过 QQ 分享链接或歌单 ID 导入；可新建或合并到已有歌单，每个自建歌单最多 1000 首。歌单歌曲支持多选播放、加入队列、喜欢、下载、添加到自建歌单及从自建歌单批量移除。
- 列表页直接展示歌曲、筛选与播放操作，不再显示占据上方空间的大幅展示区。
- 在线歌曲下载、进度显示、取消与重新下载，下载完成后可导入本地音乐库。
- 底部播放条音质选择、0.5–2 倍速、睡眠倒计时；音质选择也用于后续下载。
- 深色、浅色、跟随系统外观，预设及自定义主题色，分别保存深浅色背景。
- 完整歌词页、歌曲详情和歌词字号；桌面歌词置顶、鼠标穿透、快捷键解锁和窗口位置保存。
- 自定义标题栏、最小化、最大化、单实例启动，以及系统支持的媒体控制按键。
- 关闭时选择退出或隐藏到托盘继续播放，托盘支持唤起、播放控制、桌面歌词开关与退出；应用图标与移动端同源。

单曲循环仅在自然播放结束时重复当前歌曲，手动切歌仍会切换。播放超过 3 秒后点击上一首会先回到当前歌曲开头。随机播放在队列有多首歌曲时避免立即重复当前歌曲。

| 快捷键 | 操作 |
| --- | --- |
| `Space` | 播放 / 暂停 |
| `Ctrl+O` | 导入本地音乐 |
| `Ctrl+F` | 聚焦在线搜索 |
| `Ctrl+←` / `Ctrl+→` | 上一首 / 下一首 |
| `Esc` | 收起歌词或队列面板 |
| `Ctrl+Alt+L` | 显示 / 隐藏桌面歌词（全局快捷键） |
| `Ctrl+Alt+U` | 解锁桌面歌词（全局快捷键） |

输入框等控件获得焦点时，播放器不会抢占空格键和切歌快捷键。「设置 → 软件行为 → 启用快捷键」可统一关闭播放器快捷键与两组桌面歌词全局快捷键，重启后保持选择。

默认在线播放音质为高清 320 kbps，已手动保存的选择会保留。点击底部音质按钮可切换标准、高清或无损；在线歌曲会重新获取音源并尽量保留进度和播放/暂停状态，实际音质仍受服务提供的音源影响。本地音频保持文件原始音质。倍速支持 0.5、0.75、1、1.25、1.5、2，保持原音高并自动保存。

底部计时器按钮是睡眠定时：支持 15、30、60、90 分钟或自定义 1–1440 分钟，可重新计时或取消；截止后暂停播放，正在获取音源时也会取消播放意图。倒计时使用绝对截止时间，系统休眠唤醒后重新检查，重启应用后不恢复倒计时。此功能不是预约开始播放。

右键歌曲或点击「更多操作」可选择下一曲播放、收藏、添加到歌单、下载、复制歌名和批量操作。指定的下一曲在随机或单曲循环下也会优先播放一次，不改变播放模式；添加歌单和加入队列采用固定、不同的图标。

完整歌词支持右键复制该句或全部纯文本歌词。自由滚动时仅在当前浏览行显示时间气泡，停止操作 2 秒后恢复播放跟随，与移动端一致；左键仍可跳转播放。

榜单与分类分页缓存 10 分钟、歌单详情 15 分钟、分类 24 小时，重复及并发请求复用，按服务地址和具体列表隔离。浏览缓存只保存 JSON 信息，最多 40 项 / 2 MiB；「设置 → 浏览缓存 → 清除浏览缓存」也会清理内存中的歌曲详情缓存，保留收藏、自建歌单、下载和背景。

“我的歌单”支持按歌单名称或创建者搜索；自建和在线歌单内支持按歌名、歌手、专辑即时筛选。搜索只处理已加载的数据，不重复请求接口；可播放筛选结果，批量操作也只作用于当前结果。QQ 歌单导入支持完整链接、分享短链接、分享文本或数字 ID，解析后预览歌曲数量，可新建歌单或合并到已有歌单。重复歌曲自动跳过，超过 1000 首容量时显示实际添加和未添加数量。

最近播放页的「清空最近播放」清除全部历史（包括当前筛选隐藏的记录），保留收藏、歌单、播放队列和音频文件。普通界面文字不会被鼠标拖动选中，输入框和文本域仍可正常选择与编辑。

## 下载管理

点击在线歌曲列表的下载按钮，或底部「下载当前歌曲」，可保存完整音频。默认保存到 Windows 下载目录中的 `Xmusic` 文件夹，也可在「设置 → 下载设置」更改下载文件位置；更改后新建或重试的任务使用新目录。最多同时下载两首，等待队列最多 20 首；单个文件上限 512 MiB。

下载音质独立保存，默认无损 FLAC；封面和歌词各有独立开关，默认开启。取链、HTTP、网络或音频格式失败时按 FLAC → 320 → 128 逐档降级，首选设置不变，任务显示实际档位。暂停会中断请求，恢复重新获取地址并从头下载；不宣称断点续传。重新下载创建新任务与新文件，保留旧文件。暂停任务可跨重启保留。

完成后点击「导入本地音乐」即可加入本地库，点击文件夹按钮可打开保存位置。「清除下载记录」只删除历史，不删除已下载音频。下载服务仍使用设置中的兼容接口；是否可用取决于服务提供的歌曲音源。

从收藏、最近播放或歌单播放同一在线歌曲时，会优先使用本机已完成的下载，并自动登记到本地库。曾导入或播放过的下载歌曲保留私有歌曲关联，清空下载历史并重启后仍可离线播放；每次使用时校验文件身份和内容，文件丢失或改变时回退线上。只有 songId、尚未补全 mid 的旧在线条目仍需先联网获取标识。若本地文件无法解码，本次播放先尝试同档线上音源，再按原有规则降级。

下载音频完整落盘后，即使在附件下载或最终历史保存时异常退出，也会在下次启动时验证并恢复完整音频。下载目录、重试、恢复、删除和清理记录的状态变化与历史保存按队列事务执行，保存失败会回滚状态并显示错误，允许重试。

## 外观与桌面歌词

下载管理支持暂停、恢复、重新下载和删除。删除时可选择只删记录，或删除该任务创建的音频及封面/歌词附件；文件已被外部替换或旧记录缺少文件身份时不会误删原文件。删除音频后会同步移除本地库、队列和歌单中的失效本地引用。

设置页可切换深浅色、跟随系统、自定义主题色及背景，支持 JPG、PNG、WebP 图片（8 MB 以内）。深浅色分别保存图片，导入时压缩到最长边 1920 像素；背景叠加与移动端一致的主题色遮罩，并根据底色调整文字对比度。外观区的恢复默认会清除主界面自定义配色和图片，保留独立设置的悬浮歌词背景。点击底部封面或歌词按钮打开完整歌词页，可切换歌曲详情、调整字号、自由滚动，并点击「回到当前歌词」恢复跟随。

桌面歌词支持手动拖动窗口边缘伸缩，位置与手动背景大小都会保存，拖动不改变设置的字号。窗口最小高度按字号及行数计算，长句会向左右扩宽背景，切到短句后恢复手动宽度；超出屏幕可用宽度时保持字号并换行。播放控件位于背景外上方，鼠标进入整个歌词窗口时显示、离开约 700ms 后隐藏；移动到控件区时保持显示。单行模式保留左当前句、右下一句。换句使用较慢的 650ms 动画。可选择常用字体或输入已安装的自定义字体名称，同时作用于完整歌词页；字号、背景不透明度和 0–40 像素圆角均可调整。悬浮背景图片独立保存。

拖动背景边缘或标题可调整位置，右键当前句或下一句直接复制对应歌词。锁定后鼠标穿透且控件隐藏，可从设置页或 `Ctrl+Alt+U` 解锁。旧版仅位置配置会迁移为手动尺寸；歌词和字体引起的临时扩展不会覆盖手动尺寸。重启后需手动开启悬浮歌词，显示器断开时窗口会移回可见区域。

悬浮歌词不会创建单独的任务栏按钮；锁定、解锁和重新打开时都会保持隐藏。主窗口关闭时显示与应用主题一致的确认弹窗，可选择「退出软件」「隐藏到托盘」或取消，按 Escape 也可取消。托盘不可用时只提供退出和取消。隐藏后播放和桌面歌词继续工作，点击托盘图标或再次启动程序可恢复原窗口；托盘菜单也可切歌和退出。选择退出会停止下载并清理悬浮窗、全局快捷键与托盘图标。勾选「记住我的选择」后，下次关闭直接执行所选操作；可在「设置 → 软件行为 → 关闭主窗口时」重新选择每次询问、隐藏到托盘或退出软件。托盘不可用时会重新询问，避免后台窗口无法恢复。

设置分组使用圆角卡片，布尔选项采用与移动端一致的主题色轨道和白色滑钮，支持键盘操作。在线播放音质、下载音质、歌词字体和关闭行为统一使用主题下拉框，支持方向键选择、Enter 确定和 Escape 关闭。标题栏右上角的太阳/月亮按钮可直接切换明暗主题并保存选择；「跟随系统」仍可在设置页重新选择。完整歌词逐字染色跟随实际播放进度，暂停时停止、跳转时立即更新；浅色背景的已唱部分默认使用亮绿色，选择其他预设或自定义主题色后使用所选颜色，未唱部分使用灰色。

## 本地音乐与歌词

设置页底部的「by XG.GM」可打开项目主页。托盘菜单使用 252 像素宽的紧凑弹层，上方为圆形播放控件，中间显示歌名、歌手、收藏和队列入口，下方提供音量、静音和桌面歌词开关，“显示软件”和“退出软件”按列上下排列。切歌、收藏、音量和歌词操作保持弹层打开，失焦或按 Escape 关闭；自绘弹层不可用时回退原生菜单。

导入选择器接受 `mp3`、`flac`、`wav`、`m4a`、`ogg`、`opus`、`aac`、`webm`，单次最多选择 1000 个文件。实际可播放的编码取决于 Electron/Chromium 的解码能力；扩展名被接受不代表其中所有编码变体都受支持。

导入会记录音频原位置并读取元数据，不会复制音频。重复导入同一路径会合并；从音乐库移除只删除应用内记录与相应封面缓存，原音频和歌词仍保留。移动或删除原文件后，需要重新导入。

「导入文件夹」包含子目录，单次最多导入 1000 首并扫描 20000 个目录项、16 层子目录；达到上限时提示分批选择子文件夹。目录链接和无法读取的目录会跳过。优先读取音频旁同名 JPG、JPEG、PNG 或 WebP 封面（8 MB 以内），无有效同名封面时使用内嵌封面；重新导入可给已有歌曲补齐缺失封面，歌曲标识保持不变。

歌曲详情与移动端采用相同的信息分组：基础信息显示歌曲名、歌手、语种、流派、专辑和专辑发行时间；更多信息显示时长、唱片公司与来源，并在服务提供时显示简介。在线歌曲打开详情时读取歌曲信息接口，本地歌曲使用文件内已有标签，缺失信息显示「未提供」。

本地音频通过应用专用的 `xmusic-audio` 协议按文件标识读取，支持 `GET`、`HEAD` 及单段字节 `Range` 请求，可按需读取和拖动播放进度。

将同名 `.lrc` 放在音频旁，例如：

```text
Music/
  晴天.flac
  晴天.lrc
```

歌词支持 UTF-8，以及带 BOM 的 UTF-16LE，单个文件不超过 2 MiB。在线 QRC 不可用时自动回退普通 LRC；真实逐字时间需要歌曲提供 QRC 数据。没有歌词时可正常播放音频；暂不支持 GBK 自动识别或嵌入音频标签的歌词。

## 在线服务

在线播放使用受限的 `xmusic-online` 原生音频通道，按真实文件头修正 MIME 并流式转发 Range 请求，避免上游把 FLAC 标成 OGG 等格式问题。播放地址请求跳过 HTTP 缓存；音频链接返回 401/403/404/410 时先同音质重新解析一次并恢复原 Range 请求。地址缓存被回收时同档重新加载并保留进度；刷新后仍失效会明确报错，避免反复降级。其他加载或解码失败仍可尝试下一档音质，保留首选音质、播放意图和进度；暂停或切歌会使旧恢复请求失效。

快速切歌会取消上一首尚未完成的音源准备请求，迟到的详情或本地文件检查不会再启动旧请求；已经用于播放或进度跳转的流不受新准备请求的清理影响。首次播放在等待期间被暂停、或先切换音质后开始播放，也会在真正开始后正确记录最近播放。

自定义音乐接口默认隐藏。连续点击侧栏设置旁的版本号五次，再输入开发者密钥 `XG2020`，即可在本次运行中显示接口设置。地址留空使用移动端一致的内置服务；自定义地址应为 HTTP 或 HTTPS 根地址（可带路径前缀），不能包含用户名、密码、查询参数或片段。

桌面主进程请求现有移动端兼容接口，渲染页面通过受限桥接调用：

| 接口 | 请求参数 | 预期响应内容 |
| --- | --- | --- |
| `GET /api/search` | `keyword`、`type=song/playlist`、`num=30/20`、`page` | `data.list` 歌曲或歌单数组 |
| `GET /api/song/url` | `mid`、`quality=128/320/flac` | `data[mid]` 为非空 HTTP(S) 播放地址 |
| `GET /api/lyric` | `mid`，或只有数值标识时使用 `id`；优先 `qrc=true` | `data.lyric` 歌词文本 |
| `GET /api/top` | 无参数，或 `id`、`num` | 分组榜单或榜单歌曲 |
| `GET /api/playlist` | `id`、`num` | 歌单信息与 `songlist` |
| `GET /api/song/detail` | `mid` 或 `id` | 完整歌曲信息、语种、流派、发行日期、唱片公司与简介，也用于补全榜单播放标识 |

歌单分类和分类歌单使用与移动端相同的 QQ 公开接口，由主进程固定请求 `c.y.qq.com`，不受自定义音乐接口地址影响。自建歌单与收藏歌单只保存在本机；收藏在线歌单后，打开时重新读取其歌曲。

内置榜单服务返回普通 HTTP 403 时，会在同一请求时限内尝试 QQ 官方 `u.y.qq.com` 榜单接口，显示该接口提供的实时榜单与完整歌曲信息。自定义服务、明确的浏览器验证、其他错误不会自动切换来源；无法加载时保留实际错误提示。

搜索兼容 QQ 常见字段，例如 `mid/songmid`、`title/name/songname`、`singer` 和 `album`。播放需要歌曲的 `mid`。在线播放地址按需解析，不写入持久化队列；高音质没有有效地址时依次尝试较低音质。网络错误、接口错误及无法获取播放地址都会显示提示。在线可用性和实际音质取决于服务及歌曲权限。

## 数据保存

- 关闭行为和快捷键开关保存在 `preferences.json`；可清除的榜单/歌单浏览缓存使用 `xmusic:discoveryCache`，与用户音乐库分开保存。

- 本地文件路径、标识和元数据保存在 Electron `app.getPath('userData')` 下的 `audio-library.json`；提取的封面保存在该目录的 `artwork` 文件夹。
- 下载目录和最近 200 条下载历史保存在 `downloads.json`；悬浮歌词位置、手动大小与锁定状态保存在 `desktop-lyrics.json`，字体、字号、单行模式和圆角使用渲染页面的本地存储。
- 收藏、最近播放、队列、当前歌曲标识、循环模式、音量、音质和接口设置使用应用渲染页面的 `localStorage`，键名前缀为 `xmusic:`。这些数据也由 Electron 用户配置目录管理，但不在 `audio-library.json` 内。
- 自建歌单和在线歌单收藏保存在 `xmusic:playlistLibrary`，自建歌单每个最多 1000 首；移出歌单或删除歌单不会删除音频文件。
- 重启会恢复队列和选择，**不会自动播放**，也不会恢复上次的秒数进度。再次播放时会重新解析需要的地址。

Windows 用户数据默认位于 `%APPDATA%` 下的应用目录，开发版与打包版目录可能不同。测试时可通过绝对路径环境变量 `XMUSIC_USER_DATA` 使用独立配置目录。便携版表示无需安装，用户数据仍使用 Electron 用户目录，不会自动保存到 EXE 旁。当前数据仅保存在这台电脑上，没有账户同步。

## 检查与打包

在 Windows 中可直接双击 `build-test-exe.cmd`：它会检查 Node.js 版本、安装锁定版本的项目依赖、运行测试，随后在本机构建安装包和便携 EXE，完成后在窗口中显示可运行的文件路径。需要 Node.js 22.12 或更新版本及网络连接；脚本不会自动安装或启动生成的播放器，也不会发布 Release。

以下命令均在 `desktop` 目录执行：

| 命令 | 用途 |
| --- | --- |
| `npm run dev` | 启动 Vite 与 Electron 开发客户端 |
| `npm run dev:web` | 仅启动 Vite 界面预览 |
| `npm start` | 用 Electron 打开已有生产构建 |
| `npm run typecheck` | TypeScript 类型检查 |
| `npm test` | 运行 Vitest 测试与 `electron/*.test.cjs` 主进程测试 |
| `npm run test:smoke` | 使用已有 `dist` 和隐藏 Electron 窗口运行端到端测试 |
| `npm run build` | 类型检查并生成 `dist` |
| `npm run pack:win` | 构建并生成 Windows x64 未安装目录 |
| `npm run dist:win` | 构建 Windows x64 NSIS 安装包和便携 EXE |

测试包含歌词与队列逻辑、主题可读性和存储、音质切换与倍速、睡眠计时及取消、异步切歌、下载进度与取消/重试/同名文件保护，以及本地文件注册、字节范围读取和接口参数校验。

实机冒烟测试需先执行 `npm run build`，再执行 `npm run test:smoke`。测试生成静音 WAV 和 LRC，使用 `.test-data/` 下的独立资料与下载目录及本机模拟音乐接口，检查导入、播放、歌词跳转、音质/倍速/睡眠计时、真实 HTTP 下载及字节一致性、收藏和重启保存，并输出截图。它不会读写日常音乐库。设置 `XMUSIC_EXECUTABLE` 为打包后的 `Xmusic.exe` 绝对路径，可测试打包版本。自动测试验证软件状态与解码播放链路，不替代音乐听感、全局快捷键冲突或所有多显示器组合的人工验证。

```powershell
npm test
npm run dist:win
```

产物写入 `desktop/release`：

- `Xmusic-<版本号>-setup.exe`：可选择安装目录的 NSIS 安装包。
- `Xmusic-<版本号>-portable.exe`：便携启动文件。
- `win-unpacked/`：解包后的应用目录，`npm run pack:win` 可只生成此目录。

当前版本号由 `package.json` 定义。安装包未做代码签名，Windows 可能显示未知发布者提示。
